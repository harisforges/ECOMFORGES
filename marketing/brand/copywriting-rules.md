# Copywriting Rules

Use PAS where appropriate:
1. Problem
2. Agitate
3. Solution

Apply WIIFM:
Always answer “What’s in it for me?” for the owner.

Use hyperlocal context naturally, especially KL/Selangor:
Puchong, Shah Alam, PJ, Subang, Klang, Kajang, Bangi, Cyberjaya, Setia Alam.

Rules:
- Start with a real ecommerce problem.
- Be specific.
- Challenge assumptions.
- Educate rather than hype.
- Never invent proof.
- Never invent statistics.
- Never promise guaranteed performance.
- Do not portray EcomForges as a generic agency.
- Sell clarity and decision quality, not call count.
- Keep CTAs clear.
